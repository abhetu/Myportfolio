# My Portfolio Website

Welcome to the repository for my personal portfolio website! This project showcases my skills, experience, and various projects I've worked on. It serves as a professional online presence to display my work, resume, and contact information.

## Live Demo

You can view the live version of the portfolio here: [My Portfolio](https://abhetu.github.io/Myportfolio/)

## Features

- **About Me Section**: A brief introduction about myself, my background, and my interests.
- **Skills Section**: Displays a list of technical and soft skills I possess, including the technologies and tools I am proficient in.
- **Experience Section**: Highlights my past work experiences and internships.
- **Projects Section**: Showcases the projects I've worked on, including detailed descriptions and links to their GitHub repositories.
- **Contact Section**: Provides a way to reach me directly through a contact form.

## Technologies Used

- **HTML** for structure
- **CSS** for styling (with Bootstrap and custom styles)
- **JavaScript** for interactive elements
- **GitHub Pages** for deployment
